# 第8题中文演示录制脚本

本文件是本人录制时使用的操作提纲，**不是已经录制的视频**。录制前按README在独立数据库准备四账号，自己记住密码，不在录像、终端或对话文件中暴露密码/密钥/Cookie。不要删原运行库来准备演示。

建议先练习一遍，再正式录制；官方建议开启前置摄像头，可使用飞书或腾讯会议，时间不限。格式和提交平台以老师正式通知为准。下面工单编号以实际提交生成的编号为准，不能依赖固定#1。

## 录制前

1. 新目录按README安装、init-db、seed-demo，打开本机服务；准备学生甲乙、维修员甲乙。
2. 确认能看到页面与两种图表；选择桌面宽度，关闭个人消息和其他含隐私窗口。
3. 建议准备两个浏览器窗口：一个学生角色、一个维修角色；普通窗口共享Cookie时要显式退出再登录，或使用独立隐私窗口。
4. 打开 `docs/ACCEPTANCE_RESULTS.md` 和最新测试输出，分清自动化证据、代理浏览器验证和本人现场操作。

## 异常展示注意

页面会隐藏非法动作按钮，不能声称没有按钮就证明服务端安全。若本人不熟悉开发者工具，展示真实独立HTTP日志作为技术证据即可，并解释它与当前浏览器演示的区别。不要为了拍错误画面修改数据库或关闭CSRF。

无效评分必须在“本人、已完成、已确认、未评分”的合法前置状态验证；对已评分单提交0分得到409只证明重复评价保护，不证明评分边界。终态保护由原负责人再次操作得到409，其他维修员不可见得到404；这两种均不得改数据。
