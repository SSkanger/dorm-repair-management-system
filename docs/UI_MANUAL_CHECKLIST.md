## Windows启动

在项目根目录打开PowerShell。已安装依赖且已有账号时，不需要重新初始化或seed：

```powershell
.\.venv\Scripts\python.exe -m flask --app run:app run --host 127.0.0.1 --port 5001 --no-reload
```

打开 http://127.0.0.1:5001/ 。账号为student_a、student_b、repairer_a、repairer_b，密码是你之前seed-demo时设置的值，没有管理员或源码默认密码。首次安装按README初始化；重复seed不会重置旧密码。停止旧服务并重启后，浏览器Ctrl+F5刷新本地CSS/JS。切勿删除旧数据库来更新UI。

## 各页步骤与预期（均需本人核验）

| 页面 | 操作 | 检查标准 |
|---|---|---|
| 未登录首页 `/` | 退出登录后访问，点击立即登录 | 品牌、流程清楚；无虚假业务数字；按钮可聚焦 |
| 登录 `/login` | 错误密码，再用student_a正确登录 | 错误提示清楚，输入宽度适当；登录后显示正确身份 |
| 概览 `/portal` | 学生甲/乙、维修甲/乙分别登录 | 卡片和最近5条只来自可见工单；零记录有空状态；维修卡片本人范围明确 |
| 提交 `/tickets/new` | 填楼栋宿舍，先交空描述，再填5字符以上描述 | 字段错误就近显示，合法位置保留；成功转真实详情；无新增假按钮 |
| 列表 `/tickets` | 按类型、状态及组合筛选，切页再清空 | AND筛选正确；页码保留条件；改变条件回第一页；统计可展开并核对 |
| 待接/本人 `/work-queue?status=PENDING`、`/my-work` | 维修甲接单后切两入口，再登录维修乙 | 待接消失，本人列表出现；维修乙不能看到甲已接单详情或数量 |
| 详情 `/tickets/<id>` | 接单→开始→完成→学生确认→评价 | 按钮仅在适当阶段出现；时间线只点亮真实已发生节点；评分、负责人、时间准确 |
| 统计 `/dashboard` | 筛选、清空、制造空结果，检查两张图 | 柱上数、环形中心数、图例和数字表一致；零类别补0；无数据布局稳定 |
| 列表内统计 | 展开统计、折叠后再展开 | 图表宽高正常、无裁切；必要时刷新并记录问题，不仅看数字表就判图表通过 |
| 长文本 | 新建接近1000字描述，查看详情 | 换行正常，不撑开整页，不隐藏完整描述 |
| 离线资源 | 已安装环境下断开外网，强制刷新统计 | 本地CSS、SVG、Chart.js仍加载；不能仅根据缓存宣称离线通过 |
